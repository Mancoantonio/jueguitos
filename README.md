# Jueguitos 🎮🔥

Personal repository where I stash my experiments with **Doom modding** (sprites, textures, DECORATE scripts, and random stuff).  
Don’t expect order or seriousness… this is pure **creative chaos**.  

## Content
- Custom sprites made in Krita.
- DECORATE actors replacements (`Zombieman`, `Imp`, `Lost Soul`, etc.).
- Custom textures (`WALRUS.WALL`, `MYWALL`, etc.).
- Various experiments to learn Slade + Ultimate Doom Builder.

## Goal
Learn how to:
- Replace and create your own enemies.
- Design textures and use them in maps.
- Build playable `.pk3` / `.wad` files without everything exploding.

## Notes
- Constantly evolving; not a finished project.  
- If something breaks: **it’s not a bug, it’s a feature** 😏.
